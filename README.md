## 🌐 Overview

**PORTFOLIO-WEB** is a production-ready, single-page personal portfolio built entirely with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies, just clean and elegant code. The design leverages **glassmorphism aesthetics** to deliver a premium, modern look that reflects Abdul Rafay's brand as an AI-assisted developer and freelancer.

```
Browser Request  ──►  index.html  ──►  style.css (Glassmorphism UI)
                                              │
                    ┌─────────────────────────┼───────────────────────┐
                    ▼                         ▼                       ▼
             Glass Navbar              Hero Section              Social Links
           [Projects | About         [WEB DEVELOPER           [LinkedIn | Facebook
            | Contact]                Headline + CTA]           | Twitter]
                                              │
                                             ▼
                                       script.js
                                   (Interactivity Layer)
```

### ✨ What This Portfolio Delivers

- 🎨 **Glassmorphism UI** — frosted glass cards, backdrop-blur effects, premium aesthetics
- 📱 **Responsive Design** — flawless layout across desktop, tablet, and mobile
- ⚡ **Zero Dependencies** — pure HTML/CSS/JS, no npm, no build step
- 🧭 **Smooth Navigation** — Projects, About & Contact sections
- 🌐 **Social Integration** — direct links to LinkedIn, Facebook, Twitter
- 🖼️ **Profile Showcase** — hero section with professional headshot

## 🚀 Getting Started

### No Installation Required

**1. Clone the repository**
```bash
git clone https://github.com/mebdulrafay/PORTFOLIO-WEB.git
cd PORTFOLIO-WEB
```

**2. Add your profile photo**
```
Place your photo at:  assets/profile.jpg
```

**3. Open in browser**
```bash
# Simply open the file — no server needed
open index.html
# or drag index.html into your browser
```

**4. (Optional) Live preview with VS Code**
```
Install "Live Server" extension → Right-click index.html → Open with Live Server
```

## ⚙️ Customization

### Update Personal Info

Open `index.html` and edit the hero section:

```html
<!-- Change headline -->
<h1>WEB DEVELOPER</h1>

<!-- Change tagline -->
<p>I'm a passionate Web Developer who loves creating modern responsive
and user friendly website</p>

<!-- Change CTA button text -->
<button>WRITE ME A MESSAGE</button>
```

### Update Social Links

```html
<div class="socials">
  <a href="https://linkedin.com/in/YOUR_PROFILE"><i class="fab fa-linkedin-in"></i></a>
  <a href="https://facebook.com/YOUR_PROFILE"><i class="fab fa-facebook-f"></i></a>
  <a href="https://twitter.com/YOUR_HANDLE"><i class="fab fa-twitter"></i></a>
</div>
```

### Change Color Theme

In `style.css`, update the root variables:

```css
:root {
  --glass-bg: rgba(255, 255, 255, 0.08);
  --glass-border: rgba(255, 255, 255, 0.15);
  --accent-color: #ec4899;       /* Change to your brand color */
  --bg-gradient: linear-gradient(135deg, #1a0533, #6b21a8);
}
```
